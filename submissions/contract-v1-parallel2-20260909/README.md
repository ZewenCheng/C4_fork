## 固定执行配置和恢复合同

生产清单默认采用批量3、4个CPU工作线程、`c4_unpadded_sdpa`和单份Qwen模型。注意力按各序列有效长度使用原SDPA算子，其他模型层批量计算；不同图片上下文隔离。输入准备及结果写入并发，证据预取有界，权重摘要和检索索引按版本复用。

SAM每张图仅算一次图像编码，词表文本编码每份冻结权重计算一次；每个查询仍独立解码。Grounding每图复用骨干，返回独立列表供下游处理，异常时恢复原forward。两套优化器缓存相互独立。

每次批量调用前持久化整批尝试次数，每图至多两次；仅失败样本重试。显存不足时减半批量至1。已完成样本必须重建验证；输入、源码、模型元数据或执行配置变化时拒绝混用恢复目录。双JSON与完成凭证成对绑定，失败或不完整结果不能替换旧作品。

直接补齐SDPA批量2实测超过517.87秒仍未完成，已中止；现有FlashAttention真实长输入预热失败。批量4和8超出显存预算。首轮全新入口在发现并验证区域重复编码瓶颈后中止，851.802秒为未完成运行，未写入正式计时。全部负面证据及首轮目录只在官方工作区保留，最终来源是parallel2新目录。
