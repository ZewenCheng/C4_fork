## 执行与恢复

先在官方实例核对模型清单和代码清单，保持现有依赖与模型路径。正常执行示例：

```sh
/workspace/result/code/run --check
/workspace/result/code/run
```

默认从`/dataset/决赛数据集1/赛题4/线上测试集`读取图片，在`/workspace/work`中新建独立工作目录，实际执行区域、特征、证据装配及条件评级，最后向`/workspace/result/result`输出双JSON。默认运行不直接复制已固定预测。也可用`--input`、`--work`、`--output`显式指定官方目录；`--resume`必须同时给出同版本工作目录。

源码、输入或资产映射变化时拒绝恢复。已发布结果被重新生成时，先在新工作目录保留旧双JSON，再替换输出；禁止直接写入固定版本目录。本次只执行run自检、独立目录真实准备及恢复自检和越界拒绝验证，没有再执行第二次全量冷启动。

仅恢复本次已固定制品时，将官方版本`submit/code`、`submit/design`、`submit/result`复制至工作作品目录并核对`package_manifest.json`。恢复旧版本前先保留当前作品；不要移动已发布标签或覆盖已评分结果。
