# 云端数据接口

Manifest采用JSONL，每行至少包含：

```json
{
  "filename": "example.jpg",
  "questionCategory": "轨道",
  "bridgeName": "",
  "image_path": "../dataset/test/轨道/example.jpg"
}
```

训练清单还需包含：

```json
{"defectType": "裂缝(混凝土裂缝)"}
```

要求：

- `filename`全局唯一；
- `image_path`可以是相对manifest的路径或云端绝对路径；
- `questionCategory`只能为“桥梁”或“轨道”；
- 训练标签必须属于锁定的22类组合；
- 测试manifest不包含人工标签；
- manifest只记录路径和结构信息，不复制图片。

本地模型不会直接修改原图：处理过程在内存中生成与初赛一致的1024像素JPEG表示。Qwen适配器则直接读取manifest指向的官方原图。

如果官方提供样例 `result.json`，推理时应使用 `--template-json`。程序只替换轨道 `defectType`，保留官方桥名和其他字段，降低格式风险。
