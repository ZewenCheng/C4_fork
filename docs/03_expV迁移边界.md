# expV迁移边界

初赛expV 85.49使用：

```text
初赛300张pQ
+ 初赛300张×5折pB/pC
→ 固定9条预测变化
```

因此，初赛expV不是一个可以直接加载后对任意新图推理的单文件模型。决赛要恢复同类能力，需要在云端重新建立：

- 5个expQ基线折模型；
- 5个EVA候选折模型；
- 每折对应的LR；
- 决赛新图片上的pB/pC；
- 只在决赛训练/验证数据上确定的残差门。

本云端包保留五个EVA折delta，但历史5个expQ折delta已缺失。因此默认使用expQ全量部署模型。不要把初赛文件名、初赛9条变化或初赛概率索引套到决赛数据。

若决赛时间有限，优先保证expQ端到端推理稳定，再在云端重训五折残差链。
