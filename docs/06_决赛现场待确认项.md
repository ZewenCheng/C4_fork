# 决赛现场待确认项

以下内容依赖决赛官方环境，赛前无法在本机最终确认：

1. 官方Qwen是OpenAI兼容HTTP接口还是本地Python SDK；
2. Qwen模型实际标识、认证方式、单次batch限制和速率限制；
3. 云端数据集挂载路径、官方训练标签文件名和样例结果路径；
4. CUDA/PyTorch预装版本及可用显存；
5. 模型包上传大小限制和是否支持预构建容器；
6. 训练检查点、特征和日志是否允许保存在云端任务目录；
7. 最终结果由脚本写入哪个规定目录。

现场最小动作：

- 根据官方说明设置 `QWEN_BASE_URL/QWEN_MODEL/QWEN_API_KEY`，或实现一个 `QWEN_PROVIDER_MODULE`；
- 用官方非测试示例运行 `preflight.py --require-qwen` 和一次Qwen冒烟；
- 使用 `build_manifest.py` 建立训练/测试清单；
- 先运行初赛expQ基线，再开始任何继续训练。

不能在现场临时做的事：

- 下载缺失的视觉模型；本包已全部带入；
- 把决赛图片传到公开Hugging Face或其他外部服务；
- 根据测试图片人工调整具体预测行；
- 把初赛expV的9条文件名规则套到决赛。
